# Liens utiles

Dépôts GitHub à garder sous la main.

| Dépôt | À quoi ça sert |
|---|---|
| [open-free-llm-api/awesome-freellm-apis](https://github.com/open-free-llm-api/awesome-freellm-apis) | Liste d'API de modèles d'IA (LLM) utilisables gratuitement |
| [usestrix/strix](https://github.com/usestrix/strix) | Agents d'IA open source pour tester la sécurité de ses propres applications |
| [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) | Plugin qui donne une mémoire persistante à Claude Code d'une session à l'autre |
| [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach) | Permet à un agent d'IA de lire et chercher sur Internet (réseaux sociaux, vidéos, sites web) |
| [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) | Catalogue officiel de plugins pour Claude Code |

## Cloner un dépôt

```bash
git clone https://github.com/open-free-llm-api/awesome-freellm-apis.git
git clone https://github.com/usestrix/strix.git
git clone https://github.com/thedotmack/claude-mem.git
git clone https://github.com/Panniantong/Agent-Reach.git
git clone https://github.com/anthropics/claude-plugins-official.git
```
